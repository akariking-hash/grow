# 쑥쑥 키린 디자인 시스템 (말해보카 스타일)

말해보카처럼 **마스코트가 말을 걸고, 버튼이 통통하게 눌리는** 게임 같은 학습앱 톤.
CSS 변수 금지 규칙에 따라 아래 값은 CSS에 직접 씁니다.

## 원칙
- 마스코트 '키린'(아기 기린)이 말풍선으로 결과를 알려준다. 숫자보다 문장이 먼저.
- 버튼·카드는 아래쪽 두꺼운 그림자(`box-shadow: 0 4~5px 0`)로 입체감, 누르면 `translateY(4px)`.
- 모서리는 크게(카드 22px, 버튼 16~20px, 칩 999px).
- 크림색 바탕 + 선명한 포인트 색. 글자 대비는 4.5:1 이상(WCAG 2.2 AA).

## 색상
| 용도 | 값 | 비고 |
|---|---|---|
| 바탕 | `#fffaf0` | 크림 |
| 카드 | `#ffffff` / 테두리 `#efe6d6` | 그림자도 `#efe6d6` |
| 본문 글자 | `#333333` | 12.1:1 |
| 보조 글자 | `#6b6b6b` | 5.1:1 (바탕 위) |
| 메인 버튼 | `#2b7a0b` / 그림자 `#1f5a07` | 흰 글자 5.4:1 |
| 링크·선택 | `#1769c2` / 연한 배경 `#e8f4fe` | 5.5:1 |
| 몸무게 | `#b45309` | 5.0:1 |
| 예상 키 | `#7a3fc4` | 6.3:1 |
| 경고·삭제 | `#c62828` | 5.6:1 |
| 장식 초록 | `#58cc02` | 글자에 쓰지 않음 (그래프 띠, 진행바) |
| 포커스 | `#3182F6` | `:focus-visible` 2px |

아이별 색 (`.kid-color1~6`, `.sib-color1~6`, `.swatch-color1~6`):

## 컴포넌트
- `.btn-primary` `.btn-secondary` `.btn-ghost` `.btn-danger`, 크기 `.btn-huge` `.btn-small`
- `.speech` (마스코트 + 말풍선), `.stat` (요약 카드 + 백분위 막대), `.card`
- `.seg` (세그먼트), `.chip` / `.swatch` (선택 칩), `.sheet` (바텀시트 / 모달)
- 마스코트 표정: `mascot-happy` `mascot-wow` `mascot-think` `mascot-sleep`

## 모션 (GSAP)
- 마스코트 둥실둥실(`y: -6`, 1.3초 반복), 탭 전환 시 카드 순차 등장, 시트는 아래에서 튀어오름(`back.out`).
- `prefers-reduced-motion: reduce` 이면 모두 끔.
